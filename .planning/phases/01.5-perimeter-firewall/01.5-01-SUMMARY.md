## Decisions Made

- `bridge-ports none` en vmbr_wan: wlan0 no puede estar en modo bridge en Linux — el kernel Host 6 debe hacer NAT (MASQUERADE). El bridge es virtual puro; OPNsense ve 172.16.0.2 como WAN con default route 172.16.0.1.
- Persistencia iptables vía post-up/pre-down: evita dependencia en `iptables-persistent`; las reglas se cargan cuando el bridge sube y se eliminan cuando baja. Patrón nativo de Proxmox, más limpio que un servicio separado.
- Dos modos en configure-vmbr-lan.sh: el conflicto vmbr0 + eth0 es arquitecturalmente ambiguo — el script no puede decidir por el operador. El modo reuse-vmbr0 solo imprime instrucciones; el operador edita manualmente para no cortar SSH.

## Checkpoint: Wave 1 — Aplicar networking en Host 6

**Tipo:** checkpoint:human-verify (gate: blocking)

### Pre-requisito obligatorio

```bash
# Verificar que wlan0 tiene IP (WiFi asociado)
ip addr show wlan0 | grep 'inet '
ping -c 3 8.8.8.8   # confirmar internet via wlan0
```

Si wlan0 no tiene IP, asociar WiFi primero:
```bash
wpa_passphrase "SSID" "PASSWORD" > /etc/wpa_supplicant/wpa_supplicant.conf
wpa_supplicant -B -i wlan0 -c /etc/wpa_supplicant/wpa_supplicant.conf
dhclient wlan0
```

### Paso 1 — Dry-run

```bash
bash scripts/proxmox/host6-firewall-setup.sh
bash scripts/proxmox/configure-vmbr-lan.sh eth0 --mode=new-bridge
```

Verificar que el bloque vmbr_wan muestra 172.16.0.1/30 y MASQUERADE.

### Paso 2 — Aplicar setup WAN

```bash
bash scripts/proxmox/host6-firewall-setup.sh --apply
```

Gates esperados:
- `[PASS] vmbr_wan bridge activo`
- `[PASS] MASQUERADE activo en cadena POSTROUTING`

### Paso 3 — Verificar MASQUERADE

```bash
iptables -t nat -L POSTROUTING -n -v | grep MASQUERADE
# Debe mostrar línea con fuente 172.16.0.0/30 destino wlan0
```

### Paso 4 — Decidir modo vmbr_lan y aplicar

```bash
# Revisar si vmbr0 ya tiene bridge-ports eth0:
grep -A5 'auto vmbr0' /etc/network/interfaces | grep 'bridge-ports'

# Si NO tiene bridge-ports eth0:
bash scripts/proxmox/configure-vmbr-lan.sh eth0 --mode=new-bridge --apply

# Si YA tiene bridge-ports eth0:
bash scripts/proxmox/configure-vmbr-lan.sh eth0 --mode=reuse-vmbr0
# (y seguir instrucciones manuales del script)
```

### Paso 5 — Verificar conectividad

```bash
ip addr show vmbr_lan   # (o vmbr0 si se usó reuse-vmbr0)
# Debe mostrar: inet 10.0.0.254/24
ping -c 3 10.0.0.10    # elastic-vm — confirmar routing MGMT intacto
```
