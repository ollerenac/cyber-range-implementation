<objective>
Prepare all prerequisite artifacts for Elastic Agent enrollment (Wave 2 plan 03-03).
Two independent tracks run in this plan:
1. Sysmon XML config merge — produce sysmon-server.xml and sysmon-workstation.xml offline using
   olafhartong/sysmon-modular Merge-AllSysmonXml, committed to scripts/windows/sysmon/
2. Fleet policy pre-configuration — create windows-target and kali-linux Fleet policies in Kibana
   with Elastic Defend DETECT mode SET BEFORE any agent enrolls (D-13 hard requirement)

enrolls. Post-enrollment mode changes require re-pushing policy to all agents. Doing this in Wave 1
(before enrollment in Wave 2) prevents the error. Sysmon XMLs must also be committed before
the WinRM enrollment script deploys them.

  <name>Task 1: Merge Sysmon XML configs offline + stage installers on elastic-vm HTTP server</name>
  <what-built>
    Two Sysmon merged XML configs produced from olafhartong/sysmon-modular using
    Merge-AllSysmonXml. Run on any machine with PowerShell (Windows, macOS, or Linux with pwsh).
    Also stages elastic-agent installer, Sysmon64.exe, and Npcap on elastic-vm's HTTP server.
  </what-built>
  <how-to-verify>
    PART A — Merge Sysmon XMLs (run on any machine with PowerShell / pwsh):

    Step 1 — Clone sysmon-modular (do NOT clone to a Windows target VM):
      git clone https://github.com/olafhartong/sysmon-modular ~/sysmon-modular
      cd ~/sysmon-modular

    Step 2 — Merge SERVER config (EventIDs 1, 3, 7, 10, 11, 12/13/14, 17/18, 22):
      pwsh -Command "
        cd ~/sysmon-modular
        . ./Merge-SysmonXml.ps1
        \$ServerModules = @(
          '1_process_creation', '3_network_connection_initiated', '7_image_load',
          '10_process_access', '11_file_create', '12_13_14_registry_event',
          '17_18_pipe_event', '22_dns_query'
        )
        \$paths = \$ServerModules | ForEach-Object { Get-ChildItem \"\$_/*.xml\" }
        Merge-AllSysmonXml -Path \$paths -AsString | Out-File sysmon-server.xml
      "
      cp ~/sysmon-modular/sysmon-server.xml /path/to/repo/scripts/windows/sysmon/sysmon-server.xml

    Step 3 — Merge WORKSTATION config (server EventIDs + 15, 23, 25, 26):
      pwsh -Command "
        cd ~/sysmon-modular
        . ./Merge-SysmonXml.ps1
        \$WorkstationModules = @(
          '1_process_creation', '3_network_connection_initiated', '7_image_load',
          '10_process_access', '11_file_create', '12_13_14_registry_event',
          '17_18_pipe_event', '22_dns_query',
          '15_file_create_stream_hash', '23_file_delete',
          '25_process_tampering', '26_file_delete_detected'
        )
        \$paths = \$WorkstationModules | ForEach-Object { Get-ChildItem \"\$_/*.xml\" }
        Merge-AllSysmonXml -Path \$paths -AsString | Out-File sysmon-workstation.xml
      "
      cp ~/sysmon-modular/sysmon-workstation.xml /path/to/repo/scripts/windows/sysmon/sysmon-workstation.xml

    Step 4 — Verify the XMLs contain EventFiltering and look correct:
      head -5 scripts/windows/sysmon/sysmon-server.xml
      grep -c "EventID" scripts/windows/sysmon/sysmon-server.xml
      grep -c "EventID" scripts/windows/sysmon/sysmon-workstation.xml
      Expected: sysmon-workstation.xml has more EventID references than sysmon-server.xml

    PART B — Stage installers on elastic-vm HTTP server:

    Step 5 — Create staging directory on elastic-vm:
      ssh elastic@10.0.0.10 "mkdir -p /opt/elastic-stage"

    Step 6 — Download elastic-agent 8.19.16 Windows installer:
      DOWNLOAD URL: https://artifacts.elastic.co/downloads/beats/elastic-agent/elastic-agent-8.19.16-windows-x86_64.zip
      Save to: /opt/elastic-stage/elastic-agent-8.19.16-windows-x86_64.zip
      scp elastic-agent-8.19.16-windows-x86_64.zip elastic@10.0.0.10:/opt/elastic-stage/

    Step 7 — Download Sysmon64.exe from Sysinternals:
      DOWNLOAD URL: https://download.sysinternals.com/files/Sysmon.zip
      Unzip to get Sysmon64.exe
      scp Sysmon64.exe elastic@10.0.0.10:/opt/elastic-stage/

    Step 8 — Copy Sysmon XML configs to staging dir:
      scp scripts/windows/sysmon/sysmon-server.xml elastic@10.0.0.10:/opt/elastic-stage/
      scp scripts/windows/sysmon/sysmon-workstation.xml elastic@10.0.0.10:/opt/elastic-stage/

    Step 9 — Start Python HTTP server on elastic-vm port 8080:
      ssh elastic@10.0.0.10 "
        cd /opt/elastic-stage
        nohup python3 -m http.server 8080 > /tmp/http-server.log 2>&1 &
        echo \$! > /tmp/http-server.pid
        sleep 1 && curl -s http://127.0.0.1:8080/ | grep 'elastic-agent'
      "
      Expected: HTML listing showing elastic-agent-8.19.16-windows-x86_64.zip

    Step 10 — From a Windows VM (e.g., dc01), verify download works:
      Invoke-WebRequest -Uri "http://10.0.0.10:8080/elastic-agent-8.19.16-windows-x86_64.zip" -OutFile "C:\Temp\test.zip"
      (Get-Item C:\Temp\test.zip).Length  # Should be > 100MB
  </how-to-verify>
  <resume-signal>Type "sysmon-staged" when: both XML files are committed to scripts/windows/sysmon/, the HTTP server is running on elastic-vm:8080, and a test download from a Windows VM succeeds</resume-signal>
