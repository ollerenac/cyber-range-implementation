<objective>
Establish the hypervisor networking fabric and storage prerequisites on all 6 Proxmox hosts so that VMs can be created in Wave 2. This delivers INFRA-01: every host exposes vmbr0 (MGMT, routes to LAN) and vmbr1 (TARGET, air-gapped — no physical uplink), with cross-host TARGET connectivity via VLAN 10 on the managed switch.

Purpose: Without isolated bridges, no target VM can be safely provisioned — an adversary-emulation lab that leaks to the LAN is unusable and dangerous. vmbr1 isolation (D-02) is the load-bearing safety property of the entire range.

Output: Per-host network config helper, Wave 0 verification scripts (isolation + storage gates), and vendor-neutral switch VLAN documentation. After this plan, all 6 hosts have correct bridges and the LVM-thin backend is confirmed.

NOTE ON SCOPE: This is greenfield infrastructure executed against bare-metal hosts. The scripts are run BY THE OPERATOR via SSH on each physical host. The plan produces the scripts and the operator-driven application + verification checkpoint.
</objective>
